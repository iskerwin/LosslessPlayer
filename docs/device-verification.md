# 真机验收

播放器 UI 按 [iOS 界面规范与验收](ios-ui-spec.md) 补充检查；特别覆盖进度取消/切歌、VoiceOver、最大字体、横屏与系统音量。

模拟器测试不覆盖文件授权和音频设备。装上开发版 IPA（或用本机签名跑 Debug）后，按下面清单勾。定位是高音质本地播放：系统可以混音，不要把某次采样率当成逐位输出。

每条记下机型、系统版本、输出设备（扬声器 / 耳机 / 蓝牙 / USB DAC）和结果。

1. **授权跨启动。** 添加一个本机音乐文件夹，确认能播放。完全划掉 App 再打开，同一首仍能播，不用重新授权。
2. **移动文件夹。** 把已授权目录改名或挪到同级位置，重新打开。预期是提示重新添加或扫描失败，而不是把资料库整库标成失效。
3. **iCloud 离线。** 选一个 iCloud 目录，先让文件下载完再播；再试一个未下载的文件。确认会提示失败或等待，而不是清掉已有索引。
4. **锁屏封面。** 播放有内嵌封面的歌，锁屏和控制中心能看到封面、标题和进度，并能暂停、切歌、拖动。
5. **拔出耳机。** 有线耳机或蓝牙播放中断开。预期暂停，而不是无声继续走进度。
6. **大 FLAC 内存。** 播放一首较长、采样率较高的 FLAC（例如 96 kHz、五分钟以上）。用 Xcode Memory Report 看内存是否随曲长线性涨到几百 MB。只记录数字，这一轮不改播放内核。
7. **文件格式和会话采样率。** 分别播 44.1 kHz 和 96 kHz（或设备上有的其他速率）。记下歌曲信息里的「音源」行，以及播放页底部的输出行（端口名和 kHz）。接 USB DAC 时确认 DAC 显示的采样率逐首跟随源文件切换、歌曲信息里的「播放路径」显示 Bit-Perfect（条件成立）；用内置扬声器播 96 kHz 时应显示已重采样到实际输出采样率。蓝牙输出应显示「无损源 · 无线输出」。
8. **专辑艺术家和合辑。** 用一张多艺术家合辑（有专辑艺术家，或只有 compilation 标记）。专辑列表应合成一张，艺术家列表仍按演唱者分开。
9. **碟号。** 抽查一张多碟专辑，曲序显示为「碟-曲号」。资料库首页没有流派、年份入口。
10. **文件夹封面。** 选一个没有内嵌封面、但目录里有 `cover.jpg` 或 `folder.jpg` 的文件夹。预期用这张图，而不是橙色占位。
11. **播放次数和最近播放。** 歌曲行副标题只有艺术家，不显示次数。排序选「播放次数」时次数高的在前。「最近播放」按时间倒序，这个页面没有排序按钮。
12. **歌单。** 底部有独立的「歌单」标签，右上角按钮在列表和网格之间切换。网格封面依次是修改过的封面、指定的歌曲封面，或前四首的拼图（不足两首时用第一首）。已在歌单页签时再点一次回到歌单首页。歌单详情是大封面、居中标题和歌曲数，下面一排是圆形随机播放、白色「播放」胶囊和圆形「添加歌曲」；空歌单只能添加歌曲。编辑、重命名、修改封面、导出和删除歌单在右上角省略号里，也可以在列表里长按歌单。编辑时可拖动排序，点「完成」退出。选歌页可逐首点选，也能「全选 / 取消全选」当前列表（有搜索词时只作用于搜索结果）。已选数量在换关键词后保留，用「添加 (N)」确认。
13. **搜索和迷你播放条。** 「搜索」是标签栏里普通的第四个标签。从别的标签点它只进入搜索，不弹键盘；已经在搜索时再点一次才弹出键盘。搜索结果按「艺术家 / 专辑 / 歌单 / 歌曲」分区：点艺术家、专辑或歌单进入对应页面，歌曲行与其它列表同一套点按播放、长按菜单和滑动操作，歌曲按标题、艺术家、专辑的匹配顺序排列；没有关键词时只显示搜索提示，不列出全部歌曲；没有结果时显示系统无结果页。iOS 26 的迷你播放条在系统的 `tabViewBottomAccessory` 里，跟着标签栏缩小。点封面、文字或空白处打开正在播放，播放和下一首仍然只控制播放。iOS 17–25 没有这个系统位置，迷你播放条放在底部安全区里：确认它不遮挡标签栏、不和列表最后一行重叠。
14. **列表上的播放和随机播放。** 歌曲、专辑、艺术家、收藏、最近播放等列表顶部只有「播放」「随机播放」两个等宽胶囊按钮（歌单详情另见第 12 条）。iOS 26 用系统 `.glass`，文字和图标是强调色（#FF2D55），不跟着当前播放变色；更早的系统用系统描边按钮。工具栏和行尾省略号是主色。点「播放」从头按顺序播放；点「随机播放」打乱后再播。正在听别的歌时，这里仍然显示「播放」。
15. **正在播放。** 全屏是封面主色的纯色背景（见第 18 条），没有「正在播放」标题和关闭按钮，顶部只有一条收起手柄，下拉收起。在封面上左右滑切歌：左滑下一首、右滑上一首，封面不跟手移动，松手后封面和标题原地切换并带很短的淡入淡出，切歌成功有一次轻触感；横向必须明显占优且超过 60pt 才触发，斜向拖动只会按纵向判断收起，两者不会同时发生。封面圆角约 12pt，暂停时略缩小。标题和艺人是白色，艺人名右边有音质小标识（无损文件为 Lossless，点按看歌曲信息），右侧只有星号和省略号，没有圆圈。进度是细白条，平时没有圆拇指；音量是系统音量条。播放控制是白色的上一首、播放、下一首，没有底。底部是歌词、AirPlay、队列三个白图标。随机和循环在队列页顶部，并跟着全局状态变。强调色不出现在这一页。
16. **歌曲菜单。** 长按或点行尾省略号，先看到封面、标题、艺术家和专辑。菜单分组依次是：收藏（再次点变为取消收藏）；添加到歌单；下一首播放、稍后播放；前往专辑、前往艺术家、识别专辑信息、更新封面（仅还没有封面的歌）、查看完整歌词（仅有歌词时）；在歌单里另有设为歌单封面、从歌单中移除；最后是从资料库中删除。删除仍按来源确认：App 内副本会写明删除副本，文件夹里的原文件不会删。专辑、艺术家和歌单长按也有播放、随机播放、下一首播放和稍后播放。下一首播放插在当前歌曲后面；稍后播放加到队列末尾。没有正在播放时，下一首播放会开始播放，稍后播放会停在第一首。
17. **整行都能播放。** 在歌曲、专辑曲目、艺术家曲目、歌单、收藏、最近播放、搜索和播放队列里，点封面、标题、艺术家之间的空隙、行尾省略号左边的空白，都应开始播放或切到这首。按下时整行有浅色高亮。只有约 44pt 宽的省略号打开菜单，长按仍是同一套菜单。歌单选歌页、资料库和搜索的入口行也是整行可点。主屏幕名称是 Lossless。
18. **过渡流畅度。** 从迷你播放器点开播放页：打开动画全程不卡顿、不跳帧；背景是当前封面主色调的纯色（深色外观压暗、浅色外观调浅，无封面时为中性灰）；音量条和 AirPlay 图标随播放页一起出现，不在打开后延迟淡入，布局不跳动。封面和顶部下拉由系统手势收起；切歌时背景色随新封面约 0.4 秒渐变。专辑、歌单页使用同一种纯色，并随系统深浅色切换。
19. **卡片转场（对照 Apple Music）。** 点迷你播放器：卡片从迷你条位置长大到全屏，迷你条内容淡出。下拉：整张卡片跟手笔直下移、不缩小，顶部圆角，资料库不变暗；拉一半推回去能回到全屏；短拉松手回弹；长拉或快甩松手缩回迷你条，迷你条随后可点。横滑封面切歌、点把手收起不受影响。连点开/关数次不闪烁、不卡死；冷启动后立刻点迷你播放器也要能打开。分别在标签栏展开态与下滑收缩两种状态下打开。打开减少动态效果后为淡入淡出。iOS 17 设备上为普通全屏弹出。

20. **播放中浏览流畅度。** 播放音乐时滚动资料库首页、专辑网格、艺术家列表和收藏页：滚动不应随播放进度（每 0.5 秒）出现周期性顿挫。收藏一首歌、播放一首新歌、删除一首歌后，收藏页、最近播放、艺术家与专辑页的内容应即时正确，不出现已删歌曲残留或新歌缺失（这些集合随资料库变更重建，播放进度不再触发全量重算）。
