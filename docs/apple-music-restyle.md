# Apple Music 风格界面改造

本次以用户提供的歌单和正在播放两张截图为视觉参考，在现有 SwiftUI / AVFoundation 原生项目上修改。没有加入在线音乐服务或改变本地音乐数据格式。

## 界面

- 歌单详情：隐藏重复的导航标题；封面宽为列表容器的 65%，最大 300pt；居中歌单名与本地歌曲数量；背景使用指定封面取色及纵向压暗。
- 操作区：48pt 圆形随机播放、白色播放胶囊、添加歌曲。空歌单禁用两个播放操作，保留添加入口；编辑排序时禁用操作区。
- 歌曲：保留封面、标题、艺人、分隔线与更多菜单，增加可用本地文件状态；原有上下文菜单、滑动删除和拖动排序保留。
- 播放页：32pt 水平边距；封面占可用舞台宽高的 90%，暂停缩放至 86%；保留上方和歌曲区之间的留白；进度静止 4pt、拖动 7pt，命中区域仍为 44pt。
- 歌曲信息：标题、艺人、收藏和更多同行组织；艺人名右侧显示音质小标识（无损文件为 Lossless，其他为格式名），点按打开歌曲信息查看完整播放路径。
- 系统音量与 AirPlay 继续使用 MPVolumeView / AVRoutePickerView；原生标签栏和 iOS 26 的玻璃底部迷你播放器保留，提升封面尺寸与文字层次。
- 封面和收起手柄下拉时跟手，主要向下且超过 90pt 后收起；不足阈值时回弹；减少动态效果设置下不应用位移和回弹动画。
- 界面强调色为 #FF2D55，保留现有 App 图标。

截图中的更新时间与在线收藏状态没有本地对应数据，因此显示实际本地歌曲数量，右侧按钮用于添加歌曲。底部保留资料库、歌单、收藏、搜索这四项实际功能。封面来自用户的音乐文件，不内置截图中的唱片美术或 Apple Music 品牌标识。

已完成：审阅代码差异、`git diff --check`、AccentColor JSON 和 project.yml 解析。

未执行：Swift 编译、XcodeGen 工程生成、XCTest、模拟器截图和真机对照。当前执行环境为 Linux，没有 Swift 编译器、Xcode 或 iOS SDK，不能将静态检查视为 iOS 构建通过，也不能宣称像素级或动态效果完全一致。

新增 UI 回归用例 `testPlayerPullDownThreshold` 覆盖短距离下拉、横向拖动不收起、长距离下拉返回迷你播放器。现有 UI 测试继续覆盖歌单截图、进度命中区和队列切换。这些用例本轮未运行。

## 在 Mac 上验收

```sh
brew install xcodegen
xcodegen generate
open LosslessPlayer.xcodeproj
```

选择签名团队和 iPhone 模拟器或真机，运行 App。先导入本地音频及封面，创建歌单并指定封面。Product → Test 运行单元和 UI 测试；测试启动参数 `-screenshotMode` 会安装离线测试曲库，不使用个人曲库。

建议重点对照：同尺寸 iPhone、暂停/播放封面比例、暖色和浅色封面的文字对比、小屏与横屏、大字体、减少透明度、队列和歌词滚动、下拉取消回弹、实体音量和 AirPlay。完整的迷你播放器连续形变，以及与截图同机同系统的像素对照，仍需后续实机校准。
