# 分类、文件夹歌单与播放页更新

## 入口与行为

- 艺术家：资料库→艺术家。优先使用 ARTISTS 多人标签，兼容 ARTIST、ARTIS、ID3 TPE1。支持分号、NUL、换行与带空格的斜线分隔；不拆开 AC/DC 或带逗号的组合名称。FLAC 增加有大小和条目限制的 Vorbis 注释读取。现有索引下一次重新扫描时会读取新版标签。
- 专辑：资料库→专辑，以自适应封面宫格显示。按标准化后的专辑名称及专辑艺术家分组；没有专辑艺术家时使用歌曲艺术家，合辑标记仍优先生效。未知专辑按原目录分开，无目录信息的导入歌曲单独分组。
- 文件夹歌单：歌单或资料库右上角菜单→从文件夹创建歌单。递归索引已选目录，为每个直接含音频文件的目录创建一个歌单；子目录使用相对路径命名。也可在管理文件夹中对已有索引执行。重复执行复用已有歌单并补入新增歌曲，保留手动排序和封面；不复制或移动原文件。
- 导入查重：按流式 SHA-256 比较文件完整内容，跳过改名、扩展名不同但字节完全相同的文件，显示导入/重复/失败数量。新扫描的文件夹歌曲也可参与与复制导入之间的比较。既有索引需重新扫描一次补齐摘要；不同编码或标签不同的文件不会仅凭歌名相同而合并。同一内容在不同文件夹的直接索引继续保留各自路径，防止破坏目录歌单关系。
- 歌单封面：列表长按或歌单详情→更多→修改封面，可从照片、文件选择或恢复自动封面。单张图片限制 20MB，保存最长边 1000 像素缩略图，封面与歌单一起持久化；仍保留从歌曲指定封面的原入口。
- 播放页：标题加粗并比副标题大；歌曲行标题使用 semibold。播放进度静止 8pt、拖动 16pt；系统音量使用 MPVolumeView 公开的轨道和 thumb 图片接口，透明 thumb、正常/高亮轨道图片分别显示 8/16pt。进度条横跨整个音量行，左端对齐小喇叭左缘、右端对齐大喇叭右缘；取消先前的左右 26pt 内缩。两侧喇叭保留原始宽高比，图像高度固定为交互轨道的 16pt，使用 28pt 容器分别向外侧对齐，与音量轨道共用中心线。时间标签靠近进度条，距最大交互轨道下缘 6pt；保留进度和音量的 44pt 交互高度，时间文字不拦截触摸。模拟器可能不显示系统音量轨道，实体音量与路由须在真机验证。
- 接下来播放：上方显示当前曲目小封面与歌曲操作，下面为圆润的随机/循环胶囊、后续歌曲和拖动排序柄。列表只显示当前歌曲之后的内容；排序和移除不会改动已播放历史或当前歌曲。只展示已实现的随机与循环操作。

## 验证

新增测试覆盖艺术家别名、多人边界、Vorbis 重复字段与损坏数据、专辑身份标准化、未知专辑目录隔离、文件夹歌单重复执行、封面持久化/恢复、索引与复制导入查重、后续队列排序/移除，以及专辑宫格和修改封面入口。最终远端编译与 XCTest 结果以 PR 的 Actions 检查为准。

播放传输按钮使用粗体、圆润设计的系统符号字体，保持原有图标尺寸、触摸区域和播放行为。
